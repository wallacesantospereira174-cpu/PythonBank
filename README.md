# 🏦 Banco Master

Projeto desenvolvido em Python para praticar **Lógica de Programação** e conceitos de **Programação Orientada a Objetos (POO)**.

O repositório conta com a evolução completa do projeto, contendo a versão inicial procedural e a versão refatorada em POO.

---

## 🚀 Funcionalidades

- **Criar Conta**: Suporte a Conta Comum e Conta Corrente (com limite de cheque especial e taxa de saque).
- **Depositar**: Entrada de valores com atualização imediata do saldo.
- **Sacar**: Validação de saldo e limite disponível com cálculo de taxas dinâmicas.
- **Transferir**: Transferências Pix/TED entre contas cadastradas.
- **Consultar Saldo & Extrato**: Exibição detalhada de titularidade, saldo, limite e histórico completo de transações.
- **Listar Contas**: Exibição estruturada de todas as contas cadastradas no sistema.
- **Excluir Conta**: Remoção de registros do sistema.

---

## 📁 Estrutura do Repositório

- `type.py` — Versão 1: Implementação funcional utilizando lógica procedural e dicionários.
- `Banco.py` — Versão 2: Implementação completa em **Orientação a Objetos (POO)** utilizando classes, herança, encapsulamento e métodos.

---

## 🛠️ Tecnologias Utilizadas

- **Python 3**
- **Paradigma Orientado a Objetos (POO)**

---

## 🎯 Objetivo

Projeto desenvolvido para consolidar conceitos fundamentais da linguagem Python, evoluindo de algoritmos procedurais para uma arquitetura orientada a objetos modular e reutilizável.
