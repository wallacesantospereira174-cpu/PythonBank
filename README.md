# 🏦 Banco Master

Projeto desenvolvido em Python para praticar lógica de programação,
estruturas de dados e manipulação de dicionários.

## Funcionalidades

- Criar conta
- Depositar
- Sacar
- Transferir 
- Consultar saldo
- Listar contas
- Excluir conta
- Histórico de transações

## Tecnologias

- Python 3

## Objetivo

Projeto criado para praticar programação e consolidar conhecimentos em Python.
